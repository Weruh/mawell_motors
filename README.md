# Mawel Motors

A simple car dealership web app built with React and Vite. Browse cars and manage listings from an admin panel.

## Tech Stack

React, Vite, React Router, Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` – start the dev server
- `npm run build` – build for production
- `npm test` – run tests
- `npm run lint` – run ESLint

## Deployment

Deploys to Firebase Hosting automatically on push to `main`.
